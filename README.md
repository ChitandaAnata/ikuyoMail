# ikuyoMail · 本地邮件客户端

一个跑在自己电脑上的通用邮箱客户端。用邮箱的 **IMAP / SMTP** 直连服务器，支持 QQ、163、126、Gmail、Outlook、iCloud、Yahoo、新浪、阿里云等主流邮箱，也能自定义任意服务商。

所有账号凭据以 AES-256-GCM 加密后只保存在本机，邮件不经过任何第三方中转。

## 下载安装

到 [Releases](https://github.com/ChitandaAnata/ikuyoMail/releases/latest) 下载 `ikuyoMail-Setup-*.exe`，双击安装即可：自带运行时，不需要装 Node 或任何依赖。



## 添加邮箱账号

点「添加邮箱账号」，选服务商 → 填邮箱地址 → 填密码。注意：绝大多数邮箱这里填的**不是登录密码**，而是单独生成的「授权码」：

| 邮箱 | 填什么 | 在哪里拿 |
| --- | --- | --- |
| QQ 邮箱 | 16 位授权码 | 网页版 → 设置 → 账号 → 开启 IMAP/SMTP → 按提示发短信获取 |
| 163 / 126 / yeah.net | 客户端授权密码 | 网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP → 设置授权密码 |
| **Gmail** | **不用授权码**，直接用 Google 账号授权 | 软件里点「使用 Google 账号登录」跟着走（页面里内置了完整图文教程） |
| **Outlook / Hotmail** | **不用授权码**，直接用 Microsoft 账号授权 | 软件里点「使用 Microsoft 账号登录」，只需先在 Azure 免费注册一个应用拿应用 ID（页面里有 8 步教程） |
| iCloud | App 专用密码 | appleid.apple.com → 登录与安全 → App 专用密码 |
| Yahoo | 应用密码 | 账号安全设置 → 生成应用密码 |
| 腾讯企业邮 | 客户端专用密码 | 管理后台 → 设置 → 客户端专用密码 |
| 新浪 / 阿里云 | 一般用登录密码 | 需先在设置里开启 IMAP/SMTP 服务 |

选好服务商后，IMAP / SMTP 服务器和端口会自动带出；特殊服务商可以展开「高级：自定义服务器」手填。

### Gmail 用 Google 账号登录

Gmail 已停用密码 / 授权码登录。软件走 Google 官方授权（OAuth2）：第一次添加时用自己的 Google Cloud 凭据（免费创建，软件里有 8 步图文教程，跟着点就行），之后点「使用 Google 账号登录」跳浏览器授权一次，收发信就不需要再管密码了，令牌自动续期。

### Outlook 用 Microsoft 账号登录

微软从 2024 年 9 月起对个人账户停用了「密码 / 应用密码」，所以 Outlook、Hotmail、Live、MSN 全都改走 Microsoft 官方授权（OAuth2）。第一次使用需要在 Azure 免费注册一个应用，拿到一个**应用 ID**（只需要这一个值，不用密钥），之后点「使用 Microsoft 账号登录」授权一次即可，软件里有完整教程。

### 某个邮箱连不上？让它单独走代理

添加或编辑账号 → 展开「代理服务器」，给这个账号单独配 SOCKS5 / HTTP 代理（其他账号不受影响）。国内网络连 Gmail 就属于这种情况。

## 功能

- 多账号并存，一键切换，账号列表显示未读数
- 收发邮件：富文本写信、抄送 / 密送、多附件、回复 / 转发自动带引用
- 搜索：按主题 / 发件人 / 收件人，中文也能搜（本地索引，毫秒级）
- 新邮件提醒：右下角弹卡片 + 提示音，窗口不在前台改用 Windows 系统通知；检查间隔可调
- 托盘常驻 + 开机自启：关掉窗口后继续在后台收信
- 右键菜单：置顶、待办、备注、另存为 PDF、标为未读 / 已读、删除
- 三栏布局可拖动调宽度，邮件可弹到独立阅读窗口
- 隐私默认拉满：正文里的外部图片默认拦截（防追踪像素），正文脚本一律不执行
- 贴边抽屉：窗口贴到屏幕顶部，鼠标移开自动收成一条边
- 连接诊断：邮件数量对不上时一键查看服务器真实状态

## 常见问题

**提示「登录被拒绝」**
先确认填的是授权码而不是登录密码，再去网页版确认 IMAP 服务已开启。QQ 邮箱频繁重试会被临时限制，等 10 分钟再试。

**提示「连接服务器超时」**
多半是网络问题（Gmail 尤其，给它配个代理），或者公司网络封了 993 / 465 端口。可以先用手机热点试一下。

**邮件数量比网页版少（163 / QQ 常见）**
通常是网页版改了「收取范围」后旧会话没刷新。点一下客户端的刷新按钮（会强制重新握手）就好。

**收不到新邮件提醒**
设置里确认「收到新邮件时提醒我」勾上了 → 托盘图标有没有出现 → 点「发一条测试提醒」验证 → 确认间隔不是 30 分钟。系统通知没有的话，检查 Windows「专注助手 / 勿扰模式」。

**改了授权码怎么办**
点账号右边的 ⚙ 打开账号设置，填新授权码保存即可（验证不过不会覆盖原配置）。

**中文显示乱码**
正常邮件不会乱码（支持 GBK / GB18030）。个别没声明字符集的邮件可能显示异常。

## 已知限制

- 贴边抽屉、托盘、系统通知是 Windows 专属；macOS / Linux 上可以从浏览器访问界面用
- 附件上限约 20MB（服务商限制），超大附件请用网盘链接
- 收新邮件靠轮询，最长要等一个间隔（默认 2 分钟）才提醒，且只在收件箱生效
- Gmail / Outlook 需要能连上各自的服务器（国内 Gmail 通常要代理，Outlook 一般可直连）
- 单机单用户设计，请勿把服务暴露到公网

## 隐私与安全

- 服务只绑定 `127.0.0.1`，不对外网开放；邮件数据、账号凭据全部只存本机
- 授权码用 AES-256-GCM 加密保存，每次改账号都在 `data/backups/` 留快照，误删可找回
- `data/` 目录等同于你的邮箱钥匙，不要提交到 git、不要发给别人

## 从源码运行

```bash
npm install
npm start        # 打开 http://127.0.0.1:7317
```

需要 Node.js 18 以上。窗口外壳、打包成 exe、安装包构建、接口文档等开发内容见 [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md)。
